P14 S5 步骤 18d：SheetHost → van-popup，17i 的 <Transition> JS 钩子整批退役

弹层外壳换成 Vant 的 van-popup：定位（fixed 贴底、宽 100%）、遮罩、滚动锁定、
z-index 分层归 Vant，.sheet 只剩「宽屏上把面板居中」+ 面板自己的样式 + 入场动画。
类名契约一个没动：#sheet 的 .on/.page、#panel、#sheetBody、.grip、.pclose 全在，
test.sh 的 8 处 #sheet.on 选择器、闸门⑥ 的 .sheet、闸门⑦ 的层叠基线全部照旧。
遮罩是 Vant 的 .van-overlay，配色与毛玻璃由 overlay-class 送进来的 .sheet-ovl 提供。

显隐照 18b/18c 走 v-if + :show="true"（Vue 的 <Transition> 靠双 rAF 排程，不可见窗口上
永不结束，见 18c 的记录），于是 17i 那套 <transition :css="false"> 的 JS 钩子
（shEnter/shLeave/shLeaveCancel/leaveMs）整批删掉。shell.sheet 新增 mounted（节点在不在）
与 on（看不看得见）分离：closeSheet = on=false 挂 .closing 播收场动画 + 定时器摘节点，
摘节点时 van-popup 的 @vue:unmounted 调 sheetLeft() 拆弹层内容的 app。
闸门⑱ 契约跟着换：@after-leave → @vue:unmounted，并新增「不许再用 <transition>」
「时长必须从样式表读（cssMs --d1）」「摘节点的定时器必须带状态守卫」三条。

两个坑：
1) cssMs 把 getPropertyValue('--d1') 读到的 "110ms" 当秒乘了 1000 → 110 秒后才摘节点，
   test.sh --vd 报「关掉弹层之后还有 sheet 活着（sheets=settings）」。CSS 时长带单位。
2) Vant 的 Overlay 组件自带 <Transition appear>，摘 van-fade-appear-from 同样要等 rAF，
   不可见窗口上遮罩永久透明；views/shell.css 钉回 opacity:1（迁移前遮罩本来就是瞬间出现）。

进度层 .ovl 的 z-index 80 → 9000：旧版 80 > sheet 40（进度层压在弹层之上），
Vant 的 popup 从 2001 起递增，固定层级的东西只能站到它上面，不能混着排。

真机计算样式对比（基线 = git stash 出 18c 的构建）：page 形态的 #sheet .panel/.phead/
.pbody/.btn、卡片形态的 #sheet .panel/.grip/.pclose/#sheetBody 全部逐字一致；#sheet 根节点
只差遮罩搬走、z-index 40→2001、max-height:100% 与根盒从满屏变成贴底内容盒（透明 +
overflow:visible，视觉零差别）；关掉之后节点与遮罩都无残留。后台屏截图核对通过。
