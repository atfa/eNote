P14 S4 步骤 17i：弹层开合交给 <Transition>（删掉 .closing + setTimeout(110) + 收场序号守卫）

closeSheet() 从此只有一句 shell.sheet.on = false。以前是「加 .closing 类 →
setTimeout(110) 拆 app → sheetGen 号防迟到的回调把新弹层拆掉」——三处必须同步的手写
动画状态机，少一处就是「弹层空白且点了没反应」。

- SheetHost 根节点 .sheet 改成 v-if（class="sheet on" 写死：元素只在开着时存在，
  :class="{on:…}" 等于 leave 第一帧就把 display:flex 抹掉），外面套 <transition>，
  @after-leave="H.sheetLeft" 里 unmountAllSheets(['progress'])。
  shell.sheet.closing 删除；sheetGen 只剩「开」这一侧要防（迟到的 nextTick 回调会把
  上一个弹层的组件挂进新面板），注释同步改写，顺手删掉重复的 var sheetGen 声明。
- CSS 模式的 <Transition> 在真机上会卡死（验收逼出来的）：Vue 用 requestAnimationFrame
  推进 CSS 过渡的状态机，页面不可见时 rAF 被挂起 → leave 永不落地 → 弹层关不掉、
  @after-leave 不调用、sheet 的 app 泄漏。test.sh 的剪贴板 raw 用例（虚拟屏 + 物理屏
  关）稳定复现：DBG close 之后 30 秒没有 sheetLeft，CPRAW mounted=1。
  改成 JS 钩子模式（:css="false" + @enter/@leave/@leave-cancelled）：shLeave 自己加类、
  用 setTimeout 收尾（后台页的 setTimeout 被节流到 1s，但它会跑），时长仍从 CSS 读
  （getComputedStyle().transitionDuration，样式表依旧是唯一时长来源）；:css="false" 时
  Vue 不给类记账，所以 leave 被取消（关掉立刻重开）要自己抹类。
- CSS：leave 类加在根元素上，面板那条改成后代选择器 .sheet.sh-leave-active .panel
  （特异度压过 base.css 的 .sheet .panel{animation:up}）；遮罩加 transition:opacity
  var(--d1)。可见差别只有一条：遮罩跟着淡出 110ms（以前瞬间消失）。
  prefers-reduced-motion 把时长归零 → 20ms 后收尾，动效开关照旧生效。
- #sheet 从常驻节点变成随开合创建/销毁：D17 测缝载荷先开一个弹层再读
  __enote.dom.sheet / panel（契约是「getter 能拿到活的节点」），读完关掉；
  test.sh:1047 改成 null 安全的 !q("#sheet.on")。
- 闸门⑱ 扩 5 条：:css="false"、@leave="shLeave"、setTimeout(done、shLeaveCancel、
  CSS 选择器形状。反向验证：删掉 :css="false" 立刻红。
