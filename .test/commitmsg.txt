notes/todos/stats/settings/sheets/files/leaf/components/blocks 里的 live(fn)
全换成裸 computed(fn)，删掉 var t = H.tick.v 这类假依赖行。
闸门⑮ 白名单从 3 个文件扩到 12 个。

三个坑：
1. live( → computed( 是字符串替换，会咬到标识符：toggleKeepAlive( 变成
   toggleKeepAcomputed(（闸门㉑ 抓到模板引用了不存在的 handler）。
2. computed 不是全局：各视图靠文件顶上的 const { computed } = Vue 拿到它，
   components/leaf.js 只 import 了 live，替换后 computed 是 undefined，setup 抛错，
   模板里 f.length 炸成 Cannot read properties of undefined (reading 'length')。
3. computed 返回容器本身 = 永远不重渲染。computed(() => H.FA) 每次返回同一个 proxy，
   reassign(FA,…) 原地改键时 computed 重算但值没变，Vue 判定「没变化」直接跳过渲染
   （症状：附件页顶部条永远停在旧数字）。解法是返回派生快照或浅拷贝，踩到 6 处：
   FileStrip、files.js、settings.js×2、stats.js、components.js。

诊断缝（永久保留）：mountView / mountSheet 都挂 app.config.errorHandler，打印
[组件名 @出错阶段] + 栈前 4 行。Vue 默认只打 message，踩过之后才知道栈才是有用的那半。
另加 window error / unhandledrejection 的栈打印。
