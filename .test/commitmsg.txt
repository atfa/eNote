P14 S5 步骤 18e：开关与骨架屏换成 Vant 组件（van-picker 判定为不适用）

⑥（Vant 组件库）的收尾。设置页两个手写开关换成 `<van-switch>`，附件页与我的页的
骨架屏换成 `<van-skeleton>`；计划里的第三项 `van-picker` 判定为不适用。

开关：状态重新成为唯一来源
- 旧写法是「像素与状态各改各的」：`onclick="toggleAI(this)"` 把元素递进函数，函数里
  `el.classList.toggle('on')` / `el.className='sw'+(on?' on':'')` 乐观改类名，500ms 后才
  `settingsRefresh()` 校准。现在 `:model-value` 读状态、`@update:model-value` 写状态，
  类名是状态的纯函数（settings.js 的 `keepSwCls` / `aiSwCls` 拼 `'sw' + (on?' on':'')`，
  test.sh 断言的 `on` 类名契约不变）。
- 三个 handler 的元素参数与两处 DOM 写操作一起删掉：`toggleKeepAlive(el)`→`()`、
  `applyKeepAlive(el,on)`→`(on)`（乐观那一步交给 computed，立刻 `settingsRefresh()`，
  500ms 那次校准保留）、`toggleAI(el)`→`()`。
- 尺寸映射是这一步全部的技术含量：Vant 的开关全部由 font-size 驱动（高 = 1em+4px、
  宽 = 1.8em+4px、圆点 = 1em、位移 = 宽−圆点−4px），旧 `.sw` 是 46×26（不是 2:1），
  所以 tokens.css 给 `--van-switch-size:22px`（高正好 26px）+ `--van-switch-width:46px`
  （位移自动算成 46−22−4 = 20px，与旧版 `left:3px→23px` 逐字相同）。圆点 22px（旧版
  20px）是这一步唯一的像素差，两边都垂直居中。
- `base.css` 三条 `.sw` 规则只剩两条：`flex:0 0 46px`（`.setrow` 给开关留的宽度）与
  `transition-timing-function:var(--ease)`（Vant 的轨道没写 timing-function、圆点写死
  `cubic-bezier(.3,1.05,.4,1.05)` 回弹，旧版两处都是 `var(--ease)`）。
  `.sw.dis{opacity:.45}` 是死代码（JS 与 test.sh 都不挂这个类），删掉，禁用态改由
  `--van-switch-disabled-opacity` 给。

骨架屏
- Vant 的骨架是「标题 + 一排等高段落」，我们是 120 / 14 / 10 px 三档，`components.css`
  用 `:nth-child` / `:last-child` 把高度与圆角补回来，动画保留我们自己的渐变扫过（`shim`）。
- `:animate="false"` 是必需的：Vant 的 `van-skeleton--animate` 给根节点挂 opacity 呼吸动画
  （实测 0.73~1 之间跳），与 shim 叠起来就是双重动画。`.skel` 类名留在根节点
  （test.sh 用它判定「还在加载」）。

闸门两处
- 常驻后台的签名断言改成新签名，并加两条负断言：`applyKeepAlive(on)` 里必须能看到
  `settingsRefresh()`、`el.className='sw'` 必须不存在 —— 防 DOM 写操作回来。
- 闸门㉔（组件模板里的自定义标签必须在自己的 `components:` 里声明）加 `van-*` 豁免，
  与闸门⑮ 同源（Vant 走 `app.use(Vant)` 全局注册）；两处豁免必须成对出现。

van-picker 判定：不适用
- app 里没有 app 内的时间选择器：添加待办的日期/时间是原生 `<input type="date">` /
  `<input type="time">`（views/sheets.js:131），点开的是系统控件。换成 van-picker 是换交互
  （滚轮 vs 系统弹窗）而不是换实现，属于新增功能；⑥ 的边界是「只用 Vant 重写已有 UI」。

设备 A/B（.test/p18sw.js + .test/cmp_sw.js，基线 = git stash 出 18d 的构建）
- 开关轨道（46×26、--grip/--acc2、background-color 0.18s）、圆点（22px、白、无阴影、位移
  20px、var(--ease)）、开/关两态与「点一下翻转」全部对齐；骨架屏三条（120/14/10 px、圆角
  12/8/8、margin 8/8/0、宽度 100%/100%/45%、渐变与 shim 动画）逐字一致。
- 四条允许的结构性等价（同一个像素的两种写法）写在比对器里：轨道圆角 999px→22px（26px
  高上都算胶囊）、圆点圆角 50%→100%、位移 transition:left→transition:transform、轨道
  transition-property:background→background-color。类名 `sw on` → `van-switch
  van-switch--on sw on`（我们的 `on` 在后，契约不变）。
- 我的页骨架屏（同一套 CSS 的两行变体）在探针里抓不到：本机 /api/stats 往返 < 16ms，
  加载帧观察不到；附件页那三行已逐字覆盖同一批规则。

tabPick("notes") 走一趟 —— tabPick 对「已经在的页签」是早退（app.js:1565 只滚回顶部），
